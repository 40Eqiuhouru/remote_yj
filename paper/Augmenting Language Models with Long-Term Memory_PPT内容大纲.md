## 04｜已有路线与 memory staleness

**核心结论**：LongMem 将记忆编码与读取解耦，稳定已缓存表示的空间。

**页面内容**：

- LongMem 将记忆编码与读取解耦，稳定已缓存表示的空间。
- 路线 | 主要做法 | 关键代价或问题
- 扩大 / 稀疏注意力 | 更长输入或稀疏连接 | 窗口、计算与训练开销
- 耦合外部记忆 | 同一模型编码并读取 | 参数更新导致旧表示陈旧
- LongMem 解耦记忆 | 冻结编码器 + 训练读取器 | 额外 SideNet 与检索成本

**讲解提示**：MemTRM使用同一模型编码历史并融合记忆，训练更新会让旧缓存和新表示出现分布差异。LongMem冻结编码骨干以解决这一来源的陈旧问题。这不等于能自动修复过期事实，也不等于检索永远正确。

**原文依据**：论文第1–2页、第4节

## 05｜基础：自回归语言模型学什么？

**核心结论**：历史记忆提供额外条件；学习目标仍是预测下一个 token。

**页面内容**：

- 历史记忆提供额外条件；学习目标仍是预测下一个 token。
- P(x₁…xₜ | memory) = ∏ᵢ P(xᵢ | x<ᵢ, memory)
- 输入
- 当前片段中的 token，以及过去片段的记忆
- 输出
- 下一个 token 的词表概率分布
- 训练目标
- 最大化正确后续 token 的对数似然

**讲解提示**：训练样本仍然是文本，不需要为每条记忆额外提供检索标签。这里的条件概率为教学记号，显式写出历史记忆。模型最终通过冻结的语言模型输出头把SideNet表示映射到词表概率。

**原文依据**：论文第2.1节，第4页

## 06｜基础：Q、K、V 与注意力

**核心结论**：用 Q 找相关 K，再按相关性加权读取 V。

**页面内容**：

- 用 Q 找相关 K，再按相关性加权读取 V。
- Attention(Q, K, V) = softmax(QKᵀ / √d) V
- Q：当前需求
- 由当前 token 的；隐藏表示投影得到
- K：可检索线索
- 计算相似度，确定；哪些历史信息相关
- V：读取内容
- 按照注意力权重；聚合为上下文表示

**讲解提示**：Q是查询，K用于匹配，V承载被读取的信息。局部注意力读取当前片段，记忆注意力读取历史检索结果。自回归的局部注意力需要因果掩码。LongMem缓存的是中间注意力K/V向量，而不是简单把原文拼进提示。

**原文依据**：论文第2.3节，式(2)，第5页

## 10｜跨网络残差：迁移骨干的表示增量

**核心结论**：SideNet 在自身计算结果上，叠加骨干跨两层的增量。

**页面内容**：

- SideNet 在自身计算结果上，叠加骨干跨两层的增量。
- HˡSide = fˡSide(Hˡ⁻¹Side) + (H²ˡLLM − H²ˡ⁻²LLM)
- 初始化
- 第 l 层 SideNet 由骨干第 2l 层参数初始化
- 自身更新
- fˡSide 计算可训练的层输出，保留层内残差
- 知识迁移
- 叠加骨干表示差值，利用预训练知识

**讲解提示**：精确对应论文式1。l为SideNet层号，对应骨干的2l层。差值代表骨干跨两层的表示变化，不是直接把两个最终输出相加。普通Transformer层内残差仍然存在；跨网络残差是额外通路。

## 12｜Token-to-Chunk：怎样检索历史？

**核心结论**：主配置：每个 token 检索 16 个块，共 64 对历史 KV。

**页面内容**：

- 主配置：每个 token 检索 16 个块，共 64 对历史 KV。
- 建立索引
- 连续 csz 个 token 为一块，对块内 K 均值池化
- 匹配候选
- 当前 Q 与块索引做内积，取 top-(K/csz) 块
- 展开读取
- 将选中的块展开，得到 K 对 token 级 K/V
- csz = 4，K = 64：16 个块 × 4 个 token；索引项由 M 降为 M/4

**讲解提示**：将连续csz个token的K均值池化得到块索引，用当前token查询与块索引点积排序。取top K/csz个块，展开为K对token级KV。每个token、每个注意力头有自己的检索结果。论文实现为GPU FAISS精确内积检索；检索选择不可微。

**原文依据**：论文第2.3节、第3.1节，第5–6页

## 13｜门控融合：当前窗口与历史各占多少？

**核心结论**：每个注意力头学习一个门控，平衡局部与记忆信息。

**页面内容**：

- 每个注意力头学习一个门控，平衡局部与记忆信息。
- H = σ(g) · A + (1 − σ(g)) · M_mem
- 局部 A
- 对当前片段做带因果掩码的自注意力
- 记忆 M_mem
- 每个 token 对自己检索出的历史 KV 做注意力
- 按头门控 g
- 可训练参数，经 sigmoid 后得到两路融合权重

**讲解提示**：先分别计算局部注意力A与记忆注意力M，再用可训练head-wise门控g的sigmoid加权。这里用M_mem避免与记忆容量M混淆。门控是按头的参数，不应解释为每个token单独预测一个动态门控。公式是记忆增强层中的注意力融合部分，后续层结构仍按论文架构处理。

**原文依据**：论文式(2)–(3)，第5页

## 20｜消融：增益是否来自记忆？

**核心结论**：同一 LongMem 推理时移除记忆：20-shot 平均下降 7.3 点。

**页面内容**：

- 同一 LongMem 推理时移除记忆：20-shot 平均下降 7.3 点。
- 移除记忆
- 66.7 → 59.4；保留 SideNet 参数；支持历史信息的作用
- 检索粒度
- ICL 的最佳 csz = 2；细粒度有助于读取；分类标签等线索
